**高频追问示例**：
```
Q: XGBoost 和 LightGBM 的区别？
A: 
  - 树的构建方式：XGBoost 按层生长（Level-wise），LightGBM 按叶生长（Leaf-wise）
  - 分裂策略：XGBoost 用预排序，LightGBM 用直方图
  - 并行化：LightGBM 的直方图算法天然支持并行
  - 内存占用：LightGBM 显著更低
  - 实际选择：大数据集选 LightGBM，小数据集差异不大

Q: L1 正则化为什么能产生稀疏解？
A: 
  - 几何解释：L1 的等值线是菱形，与损失函数等值线的交点更可能在坐标轴上
  - 导数解释：L1 在零点不可导，subgradient 的更新会使小权重直接变为零
  - 贝叶斯解释：L1 等价于 Laplace 先验，该先验在零点有尖峰
```

```python
# 1. 手写 Softmax（含数值稳定性）
def softmax(x):
    """手写 softmax，处理数值溢出"""
    x_max = np.max(x, axis=-1, keepdims=True)
    exp_x = np.exp(x - x_max)  # 防止溢出
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)


# 2. 手写 Multi-Head Attention
class MultiHeadAttention:
    def __init__(self, d_model, num_heads):
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)

        # 线性变换并分头
        Q = self.W_q(query).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = self.W_k(key).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = self.W_v(value).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)

        # 缩放点积注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / (self.d_k ** 0.5)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        attn = torch.softmax(scores, dim=-1)
        output = torch.matmul(attn, V)

        # 拼接多头并投影
        output = output.transpose(1, 2).contiguous().view(batch_size, -1, self.num_heads * self.d_k)
        return self.W_o(output)


# 3. 手写 LoRA 层
class LoRALayer:
    def __init__(self, original_linear, r=8, alpha=16):
        self.original = original_linear
        self.r = r
        self.alpha = alpha
        self.scaling = alpha / r

        d_in, d_out = original_linear.in_features, original_linear.out_features
        self.lora_A = nn.Parameter(torch.randn(d_in, r) * 0.01)
        self.lora_B = nn.Parameter(torch.zeros(r, d_out))

    def forward(self, x):
        # 原始权重 + LoRA 增量
        return self.original(x) + (x @ self.lora_A @ self.lora_B) * self.scaling


# 4. 手写 Beam Search
def beam_search(model, input_ids, beam_width=5, max_length=100):
    """简化的 beam search 实现"""
    sequences = [(input_ids, 0.0)]  # (token_ids, score)

    for _ in range(max_length):
        candidates = []
        for seq, score in sequences:
            if seq[-1] == EOS_TOKEN:
                candidates.append((seq, score))
                continue

            logits = model(seq)
            log_probs = F.log_softmax(logits[-1], dim=-1)
            top_k = log_probs.topk(beam_width)

            for i in range(beam_width):
                new_seq = torch.cat([seq, top_k.indices[i:i+1]])
                new_score = score + top_k.values[i].item()
                candidates.append((new_seq, new_score))

        # 保留 beam_width 个最优序列
        sequences = sorted(candidates, key=lambda x: x[1], reverse=True)[:beam_width]

    return sequences[0][0]


# 5. 手写 RoPE（旋转位置编码）
def apply_rope(x, seq_len, dim):
    """对输入应用旋转位置编码"""
    # x: (batch, seq_len, dim)
    freqs = 1.0 / (10000 ** (torch.arange(0, dim, 2).float() / dim))
    positions = torch.arange(seq_len).float()
    angles = torch.einsum("i,j->ij", positions, freqs)  # (seq_len, dim/2)

    cos = angles.cos()
    sin = angles.sin()

    # 将 x 分成对，应用旋转
    x1, x2 = x[..., 0::2], x[..., 1::2]
    rotated_x1 = x1 * cos - x2 * sin
    rotated_x2 = x1 * sin + x2 * cos

    return torch.stack([rotated_x1, rotated_x2], dim=-1).flatten(-2)
```

## 📝 实战面试题精选与解析

### 一、机器学习基础题

```
Q1: 解释梯度提升树（GBDT）的原理，为什么它在表格数据上表现优异？

答题要点：
1. 核心思想：多个弱学习器（决策树）顺序训练，每棵树拟合前序树的残差
2. 关键机制：
   - 损失函数的负梯度方向作为拟合目标
   - Shrinkage（学习率）控制每棵树的贡献
   - 子采样（Subsample）增加随机性
3. 表格数据优势：
   - 天然处理异构特征（不需要归一化）
   - 分裂点学习可以捕捉非线性关系
   - 对异常值鲁棒
   - 特征交互通过树深度自然建模
4. 对比深度学习：
   - 表格数据缺乏空间/序列结构，CNN/RNN 优势无法发挥
   - GBDT 的贪婪分裂相当于一种高效特征工程
   - 小数据量时 GBDT 泛化更好

Q2: 解释 Batch Normalization 的工作原理和它在训练中的作用。
    它为什么在 Transformer 中被 Layer Normalization 替代？

答题要点：
1. BN 原理：在 mini-batch 维度上归一化，保持均值 0 方差 1
2. BN 的作用：
   - 平滑优化 landscape（更平滑的损失面）
   - 允许更大学习率
   - 有正则化效果（mini-batch 的随机性）
3. Transformer 用 LN 的原因：
   - NLP 中序列长度可变，BN 的 batch 统计量不稳定
   - BN 在推理时使用移动平均，但训练/推理不一致影响效果
   - LN 在特征维度归一化，不依赖 batch size
   - Pre-Norm（在 attention/FFN 前做 LN）训练更稳定
```

### 二、大模型核心题

```
Q3: 详细解释 LoRA 的原理。为什么低秩矩阵可以有效微调大模型？

答题要点：
1. 核心假设：微调过程中权重矩阵的变化量是低秩的
2. 数学表达：W' = W + ΔW = W + BA，其中 B∈R^(d×r), A∈R^(r×k), r << min(d,k)
3. 参数量对比：
   - 全量微调：d × k 参数
   - LoRA：(d + k) × r 参数（r=8 时约 0.1% 参数量）
4. 为什么有效：
   - Aghajanyan et al. 2020 证明预训练模型的内在维度（intrinsic dimension）较低
   - 微调的权重更新方向集中在一个低维子空间
   - LoRA 直接在这个低维子空间中优化
5. 超参数选择：
   - rank r：通常 8-64，任务越复杂需要越大
   - alpha：控制缩放因子 alpha/r，通常设为 2r
   - 应用层：通常在 Q/V 矩阵上应用效果最好

Q4: 解释 RLHF 中 DPO（Direct Preference Optimization）的原理，
    相比 PPO 有什么优势？

答题要点：
1. RLHF 传统流程（PPO）：
   - Step 1: 收集人类偏好数据
   - Step 2: 训练奖励模型（Reward Model）
   - Step 3: PPO 优化策略模型最大化奖励
   - 问题：流程复杂、不稳定、奖励模型可能不准确

2. DPO 核心思想：
   - 绕过奖励模型，直接从偏好数据优化策略
   - 利用 Bradley-Terry 模型推导出闭式解
   - 损失函数：L_DPO = -log σ(β * (log π(y_w|x)/π_ref(y_w|x) 
                                      - log π(y_l|x)/π_ref(y_l|x)))
   - y_w: 偏好的回复，y_l: 非偏好的回复

3. DPO 优势：
   - 无需训练奖励模型
   - 训练更稳定
   - 实现更简单
   - 计算成本更低

4. DPO 局限：
   - 对偏好数据质量更敏感
   - 在线迭代能力不如 PPO
   - 最新改进：IPO, KTO, GRPO 等变体
```

### 三、系统设计题

```
Q5: 如何设计一个大模型的安全防护系统？

答题要点：
1. 分层防护架构：
   - 输入层：Prompt 注入检测 + 敏感信息过滤
   - 模型层：Safety RLHF + 宪法 AI + 输出约束
   - 输出层：有害内容检测 + 幻觉检测 + 合规过滤
   - 监控层：异常行为检测 + 日志审计

2. 关键技术：
   - Prompt 注入防护：分类器 + 规则引擎
   - 输出安全：多模型交叉验证
   - 幻觉检测：事实核查 + 知识库比对
   - 隐私保护：PII 检测 + 数据脱敏

3. 运营机制：
   - Red Teaming 定期攻防
   - 用户反馈闭环
   - 安全指标持续监控
```

## 🏁 结语

**面试的本质是一场双向的信息交换**：
1. 公司评估你的技术能力和团队匹配度
2. 你评估这个机会是否值得投入接下来的时间
3. 好的面试表现 = 扎实的技术功底 + 清晰的表达能力 + 真诚的态度

**给读者的最后建议**：

> "不要等到'准备好了'再面试。面试本身就是最好的学习方式。即使失败了，每一次面试都在帮你构建更完整的知识体系和表达能力。"
