# 第 1 章：AI 基础理论

> 本章是 AI 能力体系的基石，覆盖从数学基础到 AI 伦理的完整知识体系。

## 章节目标

学完本章后，你将能够：

- 理解 AI 算法背后的核心数学概念（线性代数、微积分、概率论）
- 掌握经典机器学习算法的原理与实现
- 构建深度学习模型的基础知识框架
- 认识 AI 安全与伦理的关键议题

## 章节结构

| 小节 | 主题 | 预计学时 | 难度 |
|------|------|----------|------|
| [1.1 数学与统计基础](1-1-math-basics.md) | 线性代数、微积分、概率论核心概念 | 8-10 小时 | ⭐⭐ |
| [1.2 经典机器学习算法](1-2-ml-algorithms.md) | 监督学习、无监督学习、集成方法 | 12-15 小时 | ⭐⭐⭐ |
| [1.3 深度学习基础](1-3-deep-learning.md) | MLP、CNN、RNN、Transformer 架构 | 15-20 小时 | ⭐⭐⭐⭐ |
| [1.4 AI 安全与伦理](1-4-ai-ethics.md) | 对抗攻击、公平性、可解释性 | 6-8 小时 | ⭐⭐ |

## 学习路径建议

```
第 1 周：1.1 数学基础 + 配套代码练习
         ↓
第 2 周：1.2 机器学习算法 + 实战项目
         ↓
第 3 周：1.3 深度学习 + 框架实践
         ↓
第 4 周：1.4 AI 伦理 + 案例研讨
```

## 前置知识

- 高中数学基础（函数、方程、基本集合论）
- 基础编程能力（Python 语法熟悉）
- 无 AI 经验要求 —— 本章从零开始
