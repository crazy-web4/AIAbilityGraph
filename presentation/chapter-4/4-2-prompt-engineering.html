提示词设计原则

CRISPE 框架

  • Context: 背景信息
  • Role: 角色设定
  • Instruction: 指令
  • Statement: 具体问题
  • Persona: 人格
  • Experiment: 实验输出

示例

你是一位资深 Python 工程师 (Role).
我需要调试一个并发问题 (Context).
请分析以下代码的线程安全问题
(Instruction):

[代码...]

给出修复建议和修改后的代码
(Statement).

Few-Shot Prompting


# Few-Shot 示例
prompt = """
将以下中文翻译成英文:

中文：你好，很高兴认识你
英文：Hello, nice to meet you

中文：今天天气真好
英文：The weather is really nice today

中文：我喜欢学习机器学习
英文："""

# 模型会续写：I like learning machine learning

关键：提供 2-5 个高质量示例，格式一致

思维链 (Chain of Thought)

核心思想：让模型展示推理过程，提高准确性


# 标准提示
prompt = "小明有 5 个苹果，吃了 2 个，又买了 3 个，现在有几个？"

# CoT 提示
prompt = """小明有 5 个苹果，吃了 2 个，又买了 3 个，现在有几个？

让我们一步步思考：
1. 开始有 5 个苹果
2. 吃了 2 个，剩下 5-2=3 个
3. 又买了 3 个，现在有 3+3=6 个

答案：6 个
"""

自我一致性 (Self-Consistency)


# 多次采样，投票选择
from openai import OpenAI

client = OpenAI()

def self_consistency_query(prompt, n=5):
    responses = client.chat.completions.create(
        model="gpt-4-turbo-preview",
        messages=[{"role": "user", "content": prompt}],
        n=n,  # 生成 n 个回答
        temperature=0.7
    )

    # 统计最常见答案
    answers = [c.message.content for c in responses.choices]
    from collections import Counter
    return Counter(answers).most_common(1)[0][0]

# 适用场景：数学推理、逻辑问题

提示词模板


from jinja2 import Template

# 创建模板
template = Template("""
你是一位{{ role }}专家。

任务：{{ task }}
背景：{{ context }}

要求:
- 使用专业术语
- 提供具体示例
- 输出格式：{{ output_format }}

用户问题：{{ question }}
""")

# 使用模板
prompt = template.render(
    role="机器学习",
    task="解释支持向量机",
    context="面向大学生教学",
    output_format="Markdown，包含公式和代码",
    question="什么是 SVM？"
)
