大模型训练三阶段

阶段 1: 预训练

  • 海量无标签数据
  • 自监督学习
  • 学习通用表示
  • 计算成本最高

阶段 2: SFT

  • 高质量指令数据
  • 监督学习
  • 学习遵循指令
  • 计算成本中等

阶段 3: RLHF 对齐

  • 人类偏好数据
  • 强化学习优化
  • 与人类价值观对齐
  • 计算成本较低

# 因果语言建模损失
def causal_lm_loss(logits, labels):
    """
    logits: (batch, seq_len, vocab_size)
    labels: (batch, seq_len)
    """
    shift_logits = logits[..., :-1, :].contiguous()
    shift_labels = labels[..., 1:].contiguous()

    loss_fct = nn.CrossEntropyLoss()
    loss = loss_fct(
        shift_logits.view(-1, shift_logits.size(-1)),
        shift_labels.view(-1)
    )
    return loss

RLHF - 人类反馈强化学习

核心思想：用人类偏好数据训练奖励模型，再用 PPO 优化策略

步骤 1: 训练奖励模型

收集人类偏好数据:
  (prompt, response_A, response_B, choice)

训练奖励模型:
  R_θ(prompt, response) → scalar score

步骤 2: PPO 优化

最大化奖励 + KL 惩罚:
  L(π) = E[r(x,y) - β·KL(π||π_ref)]

PPO update:
  ∇L = E[∇logπ(a|s)·A(s,a)]

RLHF 完整实现


# examples/2-2-pretraining/rlhf_example.py
from trl import PPOTrainer, PPOConfig
from transformers import AutoModelForCausalLM
from torch.nn.functional import log_softmax

# 加载 SFT 后的模型
model = AutoModelForCausalLM.from_pretrained("./sft-model")

# PPO 配置
ppo_config = PPOConfig(
    model_name="llama-2-7b-sft",
    learning_rate=1e-6,
    batch_size=32,
    mini_batch_size=4,
    ppo_epochs=4,
    init_kl_coef=0.2,
    adap_kl_ctrl=True
)

# 创建 PPO Trainer
ppo_trainer = PPOTrainer(ppo_config, model, ref_model=None)

# PPO 训练循环
for epoch in range(num_epochs):
    for batch in dataloader:
        question_tensors = batch["input_ids"]

        # 生成回复
        response_tensors = ppo_trainer.generate(question_tensors)

        # 计算奖励
        rewards = [reward_model(score) for score in batch["scores"]]

        # PPO 更新
        stats = ppo_trainer.step(question_tensors, response_tensors, rewards)
