LLM 推理瓶颈分析

计算瓶颈

  • Attention O(n²) 复杂度
  • FFN 大矩阵乘法
  • 显存带宽限制

内存瓶颈

  • 模型权重占用
  • KV Cache 增长
  • 批次数据显存
推理显存分解 (以 70B 模型为例):
├── 权重：140GB (FP16)
├── KV Cache: 可变，约 20-40GB
├── 激活值：5-10GB
└── 总需求：~200GB

KV Cache 机制

核心思想：缓存已计算过的 K、V，避免重复计算

Without Cache

每生成一个 token:
  重新计算所有位置
  的 Q, K, V

计算量：O(n²)

With Cache

每生成一个 token:
  只计算新位置的 Q,K,V
  复用历史 KV Cache

计算量：O(n)
                        

# KV Cache 显存估算
# 每层每 token 的 KV 缓存
cache_per_token = 2 * hidden_size * num_layers * 2  # K 和 V, FP16

# Llama-2-7B: hidden=4096, layers=32
# 单 token 缓存 = 2 * 4096 * 32 * 2 * 2 bytes ≈ 1MB
# 1024 长度序列 ≈ 1GB KV Cache

PagedAttention - vLLM 核心技术

受操作系统虚拟内存启发，解决 KV Cache 碎片化问题

传统方式:
  [请求 1:███████][请求 2:████][请求 3:████████]
  → 内存碎片化，无法高效利用

PagedAttention:
  请求 1: [页 0][页 3][页 1]
  请求 2: [页 2][页 5]
  请求 3: [页 4][页 6][页 7][页 0]
  → 非连续存储，按需分配

vLLM 使用示例


from vllm import LLM, SamplingParams

# 创建 LLM 实例
llm = LLM(
    model="meta-llama/Llama-2-7b-chat-hf",
    tensor_parallel_size=1,      # GPU 数量
    gpu_memory_utilization=0.9,  # GPU 显存利用率
    max_num_seqs=256,            # 最大并发序列数
    max_model_len=4096           # 最大序列长度
)

# 采样配置
sampling_params = SamplingParams(
    temperature=0.7,
    top_p=0.9,
    max_tokens=512,
    stop=["", "User:"]
)

# 批量推理
prompts = ["Hello:", "What is AI?", "Explain quantum"]
outputs = llm.generate(prompts, sampling_params)

for output in outputs:
    print(output.outputs[0].text)

连续批处理 (Continuous Batching)

传统批处理：等待整个 batch 完成；连续批处理：动态插入新请求

传统批处理:
  Step1: [A1][B1][C1][D1]
  Step2: [A2][B2][C2][D2]
  Step3: [A3][B3][C3][D3]  ← C、D 已完成但空闲等待

连续批处理:
  Step1: [A1][B1][C1][D1]
  Step2: [A2][B2][C2]      ← C 完成，立即插入 E
  Step3: [A3][B3][E1]      ← A 完成，插入 F

TensorRT-LLM 优化


import tensorrt_llm
from tensorrt_llm import Functionality

# 1. 构建优化引擎
builder = tensorrt_llm.Builder()

# 2. 配置优化选项
config = {
    "use_cuda_graph": True,      # CUDA 图
    "use_paged_attention": True, # PagedAttention
    "reduce_fusion": True,       # 算子融合
    "gemm_plugin": "auto"        # GEMM 插件
}

# 3. 导出引擎
engine = builder.build(
    model,
    config,
    max_batch_size=32,
    max_input_len=2048,
    max_output_len=512
)

# 4. 保存与部署
engine.save("llama-7b.engine")
