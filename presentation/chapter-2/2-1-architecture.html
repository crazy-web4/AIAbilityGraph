2.1.2 三种架构范式对比

架构类型 代表模型 注意力类型 适用场景
Encoder-only BERT, RoBERTa 双向自注意力 理解任务（分类、NER）
Decoder-only GPT, Llama 因果/单向注意力 生成任务（文本生成）
Encoder-Decoder T5, BART 双向 + 交叉注意力 序列到序列（翻译、摘要）

1. Encoder-only (BERT 风格)

特点：双向自注意力，可以看到所有位置


class BERTStyleEncoder(nn.Module):
    def __init__(self, vocab_size, d_model=768,
                 n_heads=12, n_layers=12):
        super().__init__()
        self.embeddings = nn.Embedding(vocab_size, d_model)
        self.encoder_layers = nn.ModuleList([
            TransformerEncoderLayer(d_model, n_heads)
            for _ in range(n_layers)
        ])
        # [CLS] token 用于分类
        self.cls_token = nn.Parameter(torch.randn(1, 1, d_model))

    def forward(self, input_ids, attention_mask=None):
        x = self.embeddings(input_ids)
        # 添加 CLS token
        cls_tokens = self.cls_token.expand(batch_size, -1, -1)
        x = torch.cat([cls_tokens, x], dim=1)
        # 编码
        for layer in self.encoder_layers:
            x = layer(x, attention_mask)
        return x[:, 0, :]  # CLS token 表示

2. Decoder-only (GPT 风格)

特点：因果掩码，只能看到过去和当前位置


class GPTStyleDecoder(nn.Module):
    def __init__(self, vocab_size, d_model=768,
                 n_heads=12, n_layers=12):
        super().__init__()
        self.token_embeddings = nn.Embedding(vocab_size, d_model)
        self.decoder_layers = nn.ModuleList([
            TransformerDecoderLayer(d_model, n_heads)
            for _ in range(n_layers)
        ])
        # 因果掩码
        self.register_buffer('causal_mask',
            torch.tril(torch.ones(max_seq_len, max_seq_len)))

    def forward(self, input_ids):
        x = self.token_embeddings(input_ids)
        # 因果掩码防止看未来
        for layer in self.decoder_layers:
            x = layer(x, self.causal_mask)
        return self.output_head(x)

2.1.3 现代大模型关键技术

🔄 RoPE 旋转位置编码

更好的外推性

⚖️ RMSNorm

更稳定、更快

🚪 SwiGLU 激活函数

比 ReLU、GELU 更好的性能

RoPE 旋转位置编码

$$q \circledast \text{RoPE}(m) \cdot k \circledast \text{RoPE}(n) = f(q, k, m-n)$$

只依赖相对位置 m-n，外推性更好


class RotaryEmbedding(nn.Module):
    def __init__(self, dim, base=10000):
        super().__init__()
        inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer('inv_freq', inv_freq)

    def forward(self, x):
        t = torch.arange(len(x), device=x.device).type_as(self.inv_freq)
        freqs = torch.einsum('i,j->ij', t, self.inv_freq)
        emb = torch.cat((freqs, freqs), dim=-1)
        return emb.cos(), emb.sin()

def apply_rotary_pos_emb(q, k, cos, sin):
    def rotate_half(x):
        x1, x2 = x[..., :x.shape[-1]//2], x[..., x.shape[-1]//2:]
        return torch.cat((-x2, x1), dim=-1)
    q_embed = (q * cos) + (rotate_half(q) * sin)
    k_embed = (k * cos) + (rotate_half(k) * sin)
    return q_embed, k_embed

RMSNorm vs LayerNorm

特性 LayerNorm RMSNorm
公式 $\frac{x-\mu}{\sigma} \cdot \gamma + \beta$ $\frac{x}{\text{rms}(x)} \cdot \gamma$
计算 减均值 + 除标准差 只除 RMS
速度 基准 快 7-10% 

class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))

    def forward(self, x):
        # 计算 RMS
        rms = torch.sqrt(torch.mean(x ** 2, dim=-1, keepdim=True) + self.eps)
        # 归一化
        return self.weight * (x / rms)
