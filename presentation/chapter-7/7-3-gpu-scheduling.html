GPU 共享技术

NVIDIA MPS

  • 多进程共享 GPU
  • 适合小模型多实例
  • 需主动管理

MIG (Multi-Instance)

  • 硬件级隔离
  • A100/H100 专属
  • 最高 7 实例/GPU

Kubernetes GPU 调度


# 限制 GPU 使用
apiVersion: v1
kind: Pod
metadata:
  name: gpu-pod
spec:
  containers:
  - name: inference
    image: ai-service:latest
    resources:
      requests:
        nvidia.com/gpu: 1  # 请求 1 个 GPU
        memory: "8Gi"
      limits:
        nvidia.com/gpu: 1
        memory: "16Gi"
---
# GPU 时间片调度 (vGPU)
apiVersion: v1
kind: ConfigMap
metadata:
  name: time-slicing
  namespace: nvidia-device-plugin
data:
  config: |
    version: v1
    sharing:
      - resources:
        - name: nvidia.com/gpu
          replicas: 4  # 1 GPU 分 4 份
