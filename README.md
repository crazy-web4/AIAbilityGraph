## 📖 项目概述

本教程旨在创建一份系统化的 AI 能力图谱，覆盖从基础数学知识到大模型应用开发的全栈能力体系。

### 核心理念

- **理论与实践结合**：每个知识点包含理论讲解 + 代码示例 + 实战案例
- **渐进式学习**：从基础到进阶，确保学习路径清晰
- **可验证性**：关键知识点配备练习题和项目实践
- **时效性**：紧跟最新技术动态

## 🚀 快速开始

### 环境要求

```bash
# Python 3.10+
python --version

# 安装核心依赖
pip install torch torchvision transformers
pip install numpy pandas matplotlib scikit-learn
pip install openai anthropic huggingface_hub
```
