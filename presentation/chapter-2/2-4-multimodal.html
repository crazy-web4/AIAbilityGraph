CLIP 核心架构

双层塔架构

    图像 Encoder      文本 Encoder
         │                │
         ▼                ▼
    图像特征向量    文本特征向量
         │                │
         └──────┬─────────┘
                ▼
        对比学习损失

对比学习损失

$$\mathcal{L} = -\frac{1}{2}\left(\log\frac{e^{sim(I,T)/\tau}}{\sum e^{sim(I,T_j)/\tau}} + \log\frac{e^{sim(I,T)/\tau}}{\sum e^{sim(I_j,T)/\tau}}\right)$$

CLIP 代码实现


import torch
import torch.nn as nn
from transformers import CLIPProcessor, CLIPModel

# 加载预训练 CLIP
model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

# 图文匹配示例
from PIL import Image
import requests

image = Image.open(requests.get("https://example.com/image.jpg", stream=True).raw)
text = "一只猫坐在沙发上"

inputs = processor(
    text=[text],
    images=image,
    return_tensors="pt",
    padding=True
)

outputs = model(**inputs)
similarity = outputs.logits_per_image  # 图文相似度

print(f"图文匹配分数：{similarity.item():.4f}")

LLaVA - 多模态对话模型

核心思想：用 CLIP 视觉 Encoder + LLM，通过投影层连接

架构组件

  • 视觉 Encoder: CLIP ViT-L/14
  • 语言模型：Vicuna/Llama
  • 投影层：2 层 MLP

训练流程

  1. 预训练：投影层对齐
  2. 微调：端到端指令微调

LLaVA 实现详解


class LLaVAModel(nn.Module):
    def __init__(self, vision_model, llm_model, hidden_size=4096):
        super().__init__()
        self.vision_encoder = vision_model
        self.llm = llm_model

        # 视觉 - 语言投影层
        self.projector = nn.Sequential(
            nn.Linear(vision_hidden, hidden_size),
            nn.GELU(),
            nn.Linear(hidden_size, hidden_size)
        )

    def forward(self, input_ids, images, attention_mask):
        # 提取图像特征
        with torch.no_grad():
            vision_outputs = self.vision_encoder(images)
            image_features = vision_outputs.pooler_output

        # 投影到语言空间
        projected = self.projector(image_features)

        # 拼接文本和图像特征
        inputs_embeds = self.llm.embed_tokens(input_ids)
        # 将图像特征插入到文本序列前
        combined = torch.cat([projected.unsqueeze(1), inputs_embeds], dim=1)

        return self.llm(inputs_embeds=combined)
