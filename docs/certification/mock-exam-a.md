## 答案与解析

> 使用方法：先独立完成全部题目再对答案。每题标注考点；错题回到 [术语表](../GLOSSARY.md) 对应词条与章节。

### 一、AI/ML 基础

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | **B** | 欺诈样本仅 0.5%，全猜"正常"就有 99.5% 准确率。类别不平衡下准确率虚高，必须看精确率/召回率/F1/PR-AUC。考点：准确率的陷阱。 |
| 2 | **D** | 交叉熵是多分类标准损失（softmax + 交叉熵），并非只能二分类；MSE 用于回归。考点：交叉熵/MLE。 |
| 3 | **B** | 训练误差低、验证误差高 = 过拟合（高方差）。对策：正则化、Dropout、增数据、早停。考点：偏差-方差。 |
| 4 | **ABD** | K-Means、PCA、关联规则都无标签；C 是有监督情感分类。考点：无监督学习。 |
| 5 | **B** | 解码器自注意力用下三角掩码，只能看左侧（因果注意力）。A 错：复杂度 O(n²)；C 错：多头为多子空间表达；D 错：注意力本身无序，需位置编码。考点：自注意力。 |
| 6 | **B** | 学习率过大导致损失震荡/发散；过小则收敛慢。考点：学习率。 |
| 7 | **B** | ReLU = max(0,x)，正区间梯度恒 1，缓解梯度消失；输出 (0,1) 的是 sigmoid。考点：激活函数。 |
| 8 | **ABC** | 残差连接、归一化、合理初始化都缓解梯度消失；D（减神经元）与梯度消失无关。考点：深度训练稳定性。 |
| 9 | **A** | KL 散度衡量分布差异，用于蒸馏、对齐等。考点：信息论基础。 |
| 10 | **C** | Bagging（随机森林）并行集成主要降方差；高偏差=欠拟合，高方差=过拟合；增数据主要降方差。考点：偏差-方差/集成。 |
| 11 | **B** | BPE 从语料学习 subword 词表，在词表大小与序列长度间折中。考点：分词。 |
| 12 | **A** | L1 产生稀疏权重（特征选择），L2 权重整体平滑变小；L2 对应高斯先验，L1 对应拉普拉斯先验。考点：正则化。 |

### 二、大模型核心技术与微调

| 题号 | 答案 | 解析 |
|------|------|------|
| 13 | **B** | 预训练 = 海量文本上的因果语言建模（next-token 预测）。考点：预训练目标。 |
| 14 | **B** | Chinchilla：算力约束下参数与 token 等比例放大（约 20 token/参数），很多早期大模型"训练不足"。考点：Scaling Law。 |
| 15 | **ABD** | SFT、RLHF/DPO、RFT 都属后训练；C 是预训练本身。考点：预训练 vs 后训练。 |
| 16 | **C** | LoRA 推理时可合并 `W'=W+BA·scale`，无额外延迟；C 说"无法合并"错误。考点：LoRA。 |
| 17 | **B** | QLoRA = NF4 4bit 量化基座 + LoRA + 双重量化 + 分页优化器，单卡可微调大模型。考点：QLoRA。 |
| 18 | **B** | DPO 无需显式奖励模型和在线 RL，用成对偏好数据直接优化，简单稳定；不保证分数更高。考点：DPO vs PPO。 |
| 19 | **ABC** | RLHF 三步：SFT → 奖励模型 → PPO 优化；D 明显错误。考点：RLHF。 |
| 20 | **C** | 增大学习率且不混通用数据会加剧遗忘；回放、小 LR、PEFT、多任务混合都是缓解手段。考点：灾难性遗忘。 |
| 21 | **B** | MoE 每 token 由路由选少数专家，总参数量大但单 token FLOPs 小。考点：MoE。 |
| 22 | **B** | KV Cache 缓存历史 K/V 避免自回归重复计算，是推理显存核心。考点：KV Cache。 |
| 23 | **ABD** | GQA/MQA、MLA、KV 量化都减少 KV 显存；C 增大窗口反而增加。考点：KV Cache 优化。 |
| 24 | **A** | LLaVA = 视觉编码器 + 投影层（把视觉特征映射为 token）+ LLM。考点：多模态架构。 |

### 三、工程化

| 题号 | 答案 | 解析 |
|------|------|------|
| 25 | **B** | TP 每层都要通信，需节点内 NVLink 高带宽；PP 通信少可跨节点。考点：并行策略拓扑。 |
| 26 | **A** | ZeRO 分片优化器状态/梯度/参数（Stage 1/2/3）消除冗余显存。考点：ZeRO。 |

| 29 | **B** | 投机解码用小模型起草、大模型并行校验，接受/拒绝采样保证输出分布不变（无损）。考点：投机解码。 |
| 30 | **B** | 量化降显存、提吞吐，代价是少量精度损失；需评测验证。考点：量化。 |
| 31 | **ABC** | 缓存、小模型路由、批处理都省钱；D 全用最大模型最贵。考点：推理成本优化。 |
| 32 | **B** | Prefill 并行处理 prompt（compute-bound），Decode 逐 token 生成（memory-bound）；分离式部署据此。考点：Prefill/Decode。 |
| 33 | **B** | 流式 SSE 主要改善 TTFT，让用户立刻看到开始输出，总耗时变化不大。考点：流式/TTFT。 |
| 34 | **B** | 连续批处理在 token 粒度动态组批，请求可随时加入/离开，GPU 利用率远高于静态批。考点：Continuous Batching。 |

### 五、RAG

| 题号 | 答案 | 解析 |
|------|------|------|
| 43 | **ABC** | RAG 解决知识过时、幻觉、私有数据接入；D 无关。考点：RAG 价值。 |
| 44 | **B** | 标准链路：解析→分块→embedding 入库→检索→重排→生成。考点：RAG 流程。 |

| 46 | **B** | 混合检索（向量语义 + BM25 精确术语/数字）实战最优，互补而非替代。考点：混合检索。 |

| 52 | **ABD** | GraphRAG 用图谱+社区摘要，擅长全局性问题，但构建成本高，是向量 RAG 的补充而非更便宜的替代。考点：GraphRAG。 |

| 54 | **A** | 相关文档是否排前 = Context Precision（上下文精确率）；Context Recall 衡量该召回的是否都召回。考点：RAGAS。 |
