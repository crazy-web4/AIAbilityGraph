数据并行 (Data Parallelism)

核心思想：模型复制到多个 GPU，每个 GPU 处理不同数据批次

GPU 0: Model → Grad ← Data Batch 0
GPU 1: Model → Grad ← Data Batch 1
GPU 2: Model → Grad ← Data Batch 2
GPU 3: Model → Grad ← Data Batch 3
              ↓
         All-Reduce 梯度聚合
              ↓
        同步更新模型参数
                    

# PyTorch DDP 示例
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

def setup_ddp():
    dist.init_process_group("nccl")
    local_rank = int(os.environ["LOCAL_RANK"])
    torch.cuda.set_device(local_rank)

model = MyModel().cuda(local_rank)
ddp_model = DDP(model, device_ids=[local_rank])

for batch in dataloader:
    loss = ddp_model(batch)
    loss.backward()
# 自动 All-Reduce 梯度

模型并行 (Model Parallelism)

张量并行 (Tensor Parallel)

将单个矩阵运算拆分到多个 GPU

MLP 层：W · x
  GPU0: W₀ · x
  GPU1: W₁ · x
  结果拼接 → 输出

流水线并行 (Pipeline Parallel)

按层拆分模型到多个 GPU

GPU0: Layer 1-8
GPU1: Layer 9-16
GPU2: Layer 17-24
GPU3: Layer 25-32

3D 并行策略

┌─────────────────────────────────────────────┐
│           3D 并行 = Data × Tensor × Pipeline │
├─────────────────────────────────────────────┤
│  Data Parallel: 批次拆分到多节点           │
│  Tensor Parallel: 层内矩阵运算拆分         │
│  Pipeline Parallel: 层间拆分               │
└─────────────────────────────────────────────┘

典型配置 (训练 175B 模型):
  · Data Parallel: 32 路
  · Tensor Parallel: 4 路
  · Pipeline Parallel: 8 路
  总 GPU 数 = 32 × 4 × 8 = 1024 GPU

DeepSpeed ZeRO 优化

ZeRO: Zero Redundancy Optimizer，消除冗余内存占用

ZeRO 级别 优化内容 显存节省
ZeRO-1 优化器状态分片 8 倍 (Adam 状态)
ZeRO-2 + 梯度分片 再省 2 倍
ZeRO-3 + 参数分片 再省 2 倍

CPU Offload：将优化器状态、参数卸载到 CPU，进一步节省显存

FSDP - Fully Sharded Data Parallel


from torch.distributed.fsdp import (
    FullyShardedDataParallel as FSDP,
    FullStateDictConfig,
    StateDictType
)
from torch.distributed.fsdp.wrap import (
    size_based_auto_wrap_policy
)

# 创建 FSDP 模型
fsdp_model = FSDP(
    model,
    auto_wrap_policy=size_based_auto_wrap_policy,
    mixed_precision={
        "param_dtype": torch.float16,
        "reduce_dtype": torch.float16,
    },
    cpu_offload=CPUOffload(offload_params=True)
)

# 保存完整 checkpoint
save_policy = FullStateDictConfig(offload_to_cpu=True)
with FSDP.state_dict_type(fsdp_model, StateDictType.FULL_STATE_DICT, save_policy):
    checkpoint = fsdp_model.state_dict()
    torch.save(checkpoint, "model.pt")
